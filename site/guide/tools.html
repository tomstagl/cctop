5 Tools

Call counts, error rates, latency, and exactly how many tokens each tool pushed into context.

Calls

tool_calls · count

Why it mattersWhich tools actually dominate this session's activity, by call count.
What to doA tool called far more than the task seems to need can indicate retrying or inefficient exploration.

Errors

tool_errors · count

Why it mattersErrors are billed and re-injected into context exactly like successes are.
What to doThe same tool failing with the same input repeatedly is the signal to interrupt and hand the model the fix directly instead of letting it keep retrying. Advisor: A15 Error loops

p50 duration

tool_p50 · ms

Why it mattersThe typical duration for this tool — the number to expect on a normal call.
What to doRead alongside p95 rather than alone; a high median usually means the tool itself is just slow.

p95 duration

tool_p95 · ms

Why it mattersThe tail latency — what occasionally makes a turn feel much slower than usual.
What to doA high p95 on a tool that also runs in the foreground (long Bash calls, builds, test suites) is a candidate to background instead. Advisor: A10 Long foreground commands

Last call

tool_last_call · duration

Why it mattersHow long since this tool was last used — staleness, not activity.
What to doA tool or MCP server that hasn't been called in a while is still paying its schema tax on every prefix; pairs with Agents & MCP's MCP call count. Advisor: A07 Idle MCP servers

Tokens → context

tokens_to_ctx · tokens

Why it mattersExactly how much context each tool's results added — the direct, measurable cause of context growth.
What to doThe biggest single contributor here is almost always the right fix target: narrow the command, delegate to a subagent, or stop re-reading it. Advisor: A03 Runaway tool results · A04 Re-reads · A05 Exploring in the main context

Top context consumers

top_ctx · tokens

Why it mattersThe single largest results by context cost, named individually rather than summed by tool.
What to doStart with the top entry, not the tool average — one oversized result usually explains most of the growth. Advisor: A03 Runaway tool results
