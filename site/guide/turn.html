4 Turn

What the current turn is actually waiting on — the model, a hook, a permission prompt, or nothing at all.

Turn duration

turn_duration · ms

Why it mattersThe wall-clock time actually experienced — what the user waited for this turn.
What to doSplit it against API time, hook time and permission wait below to see where the time really went.

API calls

api_calls · count

Why it mattersHow many round-trips happened inside one turn — each one re-sends the entire context.
What to doA turn with many calls often means many small tool round-trips; fewer, larger tool calls usually cost less.

API time

api_time · ms

Why it mattersTime actually spent waiting on the model to respond — the baseline the other overheads are measured against.
What to doNot directly actionable; it's the number everything else in this panel is subtracted from.

Retry time

retry_time · ms

Why it mattersTime spent on requests that had to be retried — pure waste, since no new work happened during it.
What to doPersistent retries point at a network or rate-limit issue outside a single session's control, but this confirms it wasn't something you did.

Hook runs

hook_runs · count

Why it mattersHow many hooks fired during the turn — each one runs synchronously and adds to what the user waits for.
What to doA turn with unexpectedly many hook runs is worth checking against your matcher patterns. Advisor: A16 Hook overhead

Hook time

hook_ms · ms

Why it mattersThe total time hooks added to this turn, on top of the model's own response time.
What to doA slow PostToolUse or Stop hook should run asynchronously, or have its matcher narrowed to the tools and paths it actually cares about. Advisor: A16 Hook overhead

Permission wait

permission_wait · ms

Why it mattersTime the model sat completely idle waiting on a human permission decision.
What to doA tool pattern approved the same way repeatedly is a candidate for permissions.allow, which removes the prompt entirely. Advisor: A09 Permission waits

Queued prompts

queued_prompts · count

Why it mattersPrompts typed while the model was still working on the previous one.
What to doInformational — a growing queue late in a task can mean it's time to interrupt instead of keep queuing.
