glyphs — the font is the person's terminal font, and the pane cannot detect it
The TUI has Caps::detect and an ASCII fallback for a non-UTF-8 locale. The pane has neither: it draws into Claude Code, which draws into a terminal whose font cctop never sees. So glyph choice is a one-way bet, and the safe bet is what the engine itself already draws.
