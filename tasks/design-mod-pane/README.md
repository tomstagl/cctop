- `Poc1Advice.dc.html` — coach view (target), interactive.
- `Poc2Raster.dc.html`, `Poc3Image.dc.html` — chart explorations that were merged into POC 6.
- `Poc4Surfaces.dc.html` — surfaces outside the pane. Only the placed transcript rows are kept.
- `Poc5Dialog.dc.html` — the act dialog (target), interactive.
- `Poc6Charts.dc.html` — the overview (target), interactive.
- `Poc7Ghostty.dc.html` — the real cell grid in Ghostty, with pictures (graphic version).
- `Poc8TerminalApp.dc.html` — the real cell grid in Terminal.app, with cell charts (text version).
