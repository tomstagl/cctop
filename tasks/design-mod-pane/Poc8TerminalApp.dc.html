What draws what
Terminal.app can't show pictures, so cctop sends the same six charts as cells (Raster). Each cell is a half block ▀ with two colours, so a chart gets two pixels per row. Text, labels and verdicts are the same as in POC 7.
Colours
Every colour comes from the 256-colour palette, so the pane looks the same in every Terminal.app version. Shown here in Menlo when this computer has no SF Mono installed; the two have the same cell grid.
