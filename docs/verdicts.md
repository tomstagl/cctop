## Cache habits

The habit that avoids a located cache rebuild, by cause. The cache verdict's Do is the habit of the costliest avoidable rebuild; a cause with no habit is not counted as avoidable.

| Cause | Changed | Habit |
|---|---|---|
| tools_changed | an MCP tool came or went | Connect the MCP servers you need before your first prompt. |
| tools_changed | a built-in or deferred tool Claude Code loaded itself | none (not avoidable) |
| prefix_rewritten | an earlier message changed | Steer forward with a new message instead of editing or rewinding an old one. |
| params_changed | effort | Pick the effort level at the start, or change it right after /clear. |
| params_changed | model | Pick the model at the start, or switch right after /clear. |
| params_changed | request features | none (not avoidable) |
| expired | the cache expired | Reply before the cache expires, or /clear before a long break. |
| system_changed | the system prompt | none (not avoidable) |

With no avoidable rebuild, the cache verdict's Do is `Do: reply within <the entry's lifetime> so the cache stays warm.`
