# The coach's words

Generated by `cctop coach --copy-md > docs/coach-copy.md` from the code that says these words; a test fails when this file is stale. Review every cell: this is what a person reads. `{holes}` are filled from facts only (counts, sizes, prices, durations, fixed labels, a file's basename), never from what the person or the model wrote.
