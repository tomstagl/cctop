# The coach's words

Generated by `cctop coach --copy-md > docs/coach-copy.md` from the code that says these words; a test fails when this file is stale. Review every cell: this is what a person reads. `{holes}` are filled from facts only (counts, sizes, prices, durations, fixed labels, a file's basename), never from what the person or the model wrote. This file covers each rule's words, the small phrases the rules choose in code, and an example of each rule's headline, evidence line and actions taken from rules that fired on the fixture sessions (the dynamic parts there are examples); the overview's verdict sentences are in `docs/verdicts.md`.

## Rules

One row per rule and variant. A rule with variants says a different whole sentence for each case; the variant column names the case. The fix prompt is a ready prompt that is put in the box, never sent. Body, fix prompt and foot are the rule's words, as written. **Example headline, example evidence and actions are what the rule said when it fired on the fixture sessions** (`fixtures/session-*.jsonl`, the first firing of each variant): numbers, file names and tool names in them are examples, the sentence shapes are the code's. Actions are listed by kind and label, with the payload of that example; `read` means nothing to type. A variant that none of the fixtures reaches says `not fired in tests`.
