Sources: D1 session registry · D2 transcript · D2a subagent transcripts · D3 status-line JSON (shim) · D4 hooks · D5 process tree · D7 git · D8 file tool inputs · D9 price table · D10 OpenTelemetry · D11 `cost-state`.
