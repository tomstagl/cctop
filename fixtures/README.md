# Fixtures

Test inputs for cctop. Transcript fixtures are **anonymised copies of real
`~/.claude/projects/<cwd>/<session>.jsonl` files**: paths, prompts and tool
outputs are replaced with neutral text, but line types, ordering, `message.id`
repetition, `usage` fields, `cost-state`, `system` subtypes and subagent layout
are kept exactly as Claude Code wrote them. That is what the parsers are tested
against, so never hand-edit structure — regenerate from a real session with the
anonymiser instead.

Layout mirrors `~/.claude`:

- `sessions/` — session registry files
- `session-a.jsonl` — a main transcript (1463 lines, Claude Code 2.1.247,
  generated by `scripts/anonymise-transcript.py`; strings are same-length
  filler capped at 4000 chars; every Bash command reads `make check` because
  the anonymiser of the day replaced commands wholesale)
- `session-a/subagents/` — that session's subagent transcripts and meta files
- `session-b.jsonl` — the coach fixture (793 lines, 2.1.270 with 2.1.251 /
  2.1.263 segments). One real session is the spine — a 15-call exploration
  run, thirty edits, eight test runs, four commits of which the last one
  follows unchecked edits, `edited_text_file` injections, `rendered`
  attachment text, and the `/clear` it started with — and
  `scripts/compose-fixture.py` splices real line segments from other sessions
  for the moments no single session had: the four `toolDenialKind` values,
  a `TaskUpdate` to completed, a `<synthetic>` API-error line, an interrupt
  with `interruptedMessageId`, a `compact_boundary` with its
  `isCompactSummary` line and re-injected attachments, an `AskUserQuestion`
  answered after more than an hour, a captured `/context` table and the
  `continued-in` line `/clear` leaves behind. Segments are copied verbatim
  and re-chained (parent uuid, session id, shifted timestamps); the composer
  finds them by predicate, so the recipe names no ids. Anonymised with
  `--max-str 2000`; the anonymiser keeps Bash command words, flags and file
  extensions (the phase classifier needs the shape), test-runner summary
  lines in stdout, the enum-valued keys the coach parsers read, and the
  markers that identify a user line's kind.

To rebuild `session-b.jsonl` from the same sources:

```
scripts/compose-fixture.py <spine> --denials <s1> --task <s2> --synthetic <s2> \
  --interrupt <s3> --compaction <s4> --ask <s5> --context <s6> --continued <s7> raw.jsonl
scripts/anonymise-transcript.py raw.jsonl fixtures/session-b.jsonl --max-str 2000
```
